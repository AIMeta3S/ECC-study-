1. **缺失数量快速收敛（32 → 11）**：第二轮 32 项缺失中 31 项已拷贝（typescript 除外），本轮新增 11 项，全部为根目录存在的"漏拷贝"，无新增悬空引用。预计再 1–2 轮可收敛（根 scripts 树有限）。

2. **缺失结构**：8 个 script（2 hook + 6 lib，均为 hook 脚本的 require 依赖）+ 3 个 skill（全由 accessibility 的 Related Skills 引用）。

3. **方法学说明**：`.js` 的依赖以静态字面量 `require()` 提取，覆盖所有字面相对引用；极少数动态 `require(variable)` 不在此列（本轮抽查的 hook 未发现该模式）。`.json` 配置型引用在第二轮已穷尽。

4. **遗留（非本轮范围）**：第二轮第 30 项 `typescript` skill 根目录不存在，本轮未拷贝、仍悬空。建议修订 [vue-patterns/SKILL.md:470](custom-install/zh-cn/skills/vue-patterns/SKILL.md#L470) 引用，而非拷贝。该项不随收敛自动消失，需单独处理。
