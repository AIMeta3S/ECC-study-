# PHP 模式

> 本文件扩展了 [common/patterns.md](../common/patterns.md)，加入了 PHP 特定内容。

## 瘦控制器，显式服务

- 让控制器专注于传输层职责：认证、校验、序列化、状态码。
- 将业务规则移至无需 HTTP 启动即可轻松测试的应用/领域服务中。

## DTO 与值对象

- 用 DTO 替代结构复杂的关联数组，用于请求、命令和外部 API 载荷。
- 对金额、标识符、日期范围以及其他受约束的概念使用值对象。

## 依赖注入

- 依赖接口或精简的服务契约，而非框架全局对象。
- 通过构造函数传入协作者，使服务无需 service-locator 查找即可测试。

## 边界

- 当模型层承担的职责超出持久化时，将 ORM 模型与领域决策隔离。
- 用小型适配器封装第三方 SDK，使代码库的其余部分依赖你的契约，而非它们的契约。
