# 营销活动

规划并执行能转化的发布活动——而不只是能上线的活动。

## 何时启用

- 规划产品或功能发布
- 从单一产品简报构建完整内容套件
- 在撰写任何文案之前定义定位和活动角度
- 跨渠道编排多种内容类型
- 评审文案的转化质量与品牌一致性

## 不可妥协的原则

1. 先定义定位，再撰写任何文案。所有文案都源自活动角度。
2. 先调研受众，再假设你了解他们的语言或顾虑。
3. 每个交付物都必须在活动叙事弧中服务于一个明确目的。
4. 在任何格式、任何渠道上，具体性都胜过形容词。
5. 同一种声音必须贯穿每个渠道、每件作品。
6. 任何文案未通过质量门禁不得发布。

## 活动工作流

### 第一阶段：调研

使用 `market-research` 来：
- 描绘目标受众画像（jobs-to-be-done、顾虑、语言、他们当前使用的替代方案）
- 梳理 3 个以上直接或相邻竞争对手（定位、空白、信息传达弱点）
- 识别 1–3 个活动角度将利用的受众洞察

交付物：一份简短的调研简报（受众画像 + 竞争摘要 + 关键洞察）。

### 第二阶段：定位

产出：
- 核心利益陈述（一句话，不列功能清单，不用行话）
- 定位公式：「[产品] 帮助 [受众] 通过 [机制] [达成结果]」
- 活动角度：整场活动所立足的具体张力、洞察或时机
- 语气画像：在撰写前锁定（委托给 `brand-voice` 进行持久、可在会话间复用的声音捕获）

在定位和角度获批之前，不得撰写任何文案。

### 第三阶段：内容生产

按以下顺序产出——每一层都为下一层提供依据：

1. **着陆页文案**（所有部分：hero、问题、解决方案、功能、工作原理、佐证、CTA）
2. **邮件序列**（每封邮件只承担一个目的；遵循叙事弧：问题 → 教育 → 激化 → 解决方案 → 佐证 → 紧迫感 → 最终 CTA）
3. **社交帖子**（通过 `content-engine` 实现平台原生；LinkedIn 和 X 是不同的格式，而不是同一文案的尺寸缩放）
4. **短视频脚本**（按时间戳分块；为屏幕和耳朵而写，不是为页面而写）
5. **广告文案变体**（3–4 个变体，用于测试不同角度或受众细分）
6. **内容日历**（按天的日程，包含渠道、类型、时机和依赖项）

### 第四阶段：评审

对每个交付物进行门禁把关：
- 对所有 hero / above-fold 文案做 5 秒测试（清晰说明面向谁、做什么、为何现在行动）
- CTA 审计（每件作品一个，具体、有理有据——而非生硬索要）
- 跨所有渠道的语气一致性检查
- 主张审计（每个主张都具体且有据可依）
- 跨渠道一致性（广告主张与着陆页一致；邮件正文与主题一致）

## 输出契约

一场完整活动应交付：

1. **定位简报** —— 角度、核心利益陈述、语气画像
2. **着陆页文案** —— hero、问题、解决方案、功能、工作原理、佐证、CTA
3. **邮件序列** —— 每封邮件的主题 + 预览 + 正文 + CTA，按天和目的标注
4. **LinkedIn 帖子** —— 3 篇以上平台原生帖子，角度各不相同
5. **X 帖子** —— 5 篇以上独立帖子 + 1 个 thread
6. **短视频脚本** —— 2 个以上按时间戳分块的脚本，附视觉方向说明
7. **广告文案变体** —— 每个变体含短标题 / 长标题 / 正文
8. **内容日历** —— 按天的日程，包含渠道、内容类型、时机和依赖项
9. **文案评审摘要** —— 任何内容上线前标注的问题和待解决问题

## 质量门禁

交付任何作品之前：

- 每个交付物听起来都出自同一位作者
- 不留空洞的最高级或凑数形容词
- 每个 CTA 都具体且有理有据（绝不使用 "learn more" 或 "click here"）
- 跨平台不得逐字重复同一文案
- hero 文案通过 5 秒测试
- 邮件主题与正文一致（不搞诱饵替换）
- 广告主张与着陆页主张完全一致
- 任何文案若原封不动套用到同品类其他产品上都不成立

## 严格禁用项

删除并重写以下任何内容：

- "game-changing"、"revolutionary"、"world-class"、"cutting-edge"
- "In today's competitive landscape"
- 没有真实截止日期支撑的虚假紧迫感
- 没有具体数据的空洞社会证明（"thousands trust us"）
- 套话式 CTA（"learn more"、"find out more"、"click here"）
- 可以原封不动拔出来插到竞争对手活动中的文案

## 相关 skills

- `brand-voice` —— 源自原始素材的声音捕获（在内容生产之前运行）
- `content-engine` —— 平台原生内容生产
- `crosspost` —— 多平台分发
- `market-research` —— 受众与竞争情报
- `seo` —— 针对着陆页文案的页面优化
