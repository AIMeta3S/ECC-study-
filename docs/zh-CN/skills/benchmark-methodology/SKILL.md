# Benchmark Methodology

使用本 skill 将一个已圈定范围的竞品集合转化为**可比较、可辩护的分数**。每个竞品都在相同的九个维度上、采用明确的 1–5 分量表进行评估，随后以统一的 profile card 记录。一致性是关键所在：只有当相同的证据对任何竞品都能得到相同的分数时，这些分数才有意义。

## 何时启用

- 来自 competitive-platform-analysis 的、已圈定范围并分层的竞品集合已准备好打分。
- 需要跨竞品的、有证据锚定的可比分数——而非凭直觉的排名。
- 客户的战略张力（即定义其目标 white-space 的成对轴线）已经确立。
- 正准备产出 profile card，供 competitive-report-structure 组装使用。

## Client positioning brief（先行确立）

打分前，先确立客户的 positioning brief。它提供：

- **战略张力** —— 即两条轴线（例如 memorability × hireability），其交点标示出客户的目标 white-space。维度 9 始终是客户所命名的张力；两极须分别报告，绝不可取平均值。
- **差异化优势（Differentiator）** —— 构成客户护城河的因素。这决定了哪些维度对客户的定位论证最为重要。
- **品牌平衡** —— 不同战略侧重的预期组合。战略建议不得在未明示的情况下破坏这种平衡。

## 为什么选择这些维度

客户的竞争基础是**横跨两极的特定张力**，而非服务广度。各维度的权重设计旨在反映这一护城河。其中两个维度——即张力的两极——必须**独立打分、绝不合并平均**，因为客户的核心战略问题正是：竞争对手是否能同时达成这两极。

## 九个维度（含权重）

权重用于指导综合分析时的侧重，而非得出一个单一的混合分数（避免虚假的复合分数——见「偏见控制」）。总和 = 100%。

1. **定位清晰度与独特性**（18%）—— 该 studio 的定位是否锐利、可独占、且一目了然？还是泛泛而谈？
2. **品牌语调 / 文字独特性**（15%）—— 文案是否拥有可独占的语体，还是与任何一家 agency 的套话别无二致？
3. **视觉识别与站点工艺**（15%）—— 视觉系统的质量与独占性；以网站作为工艺实力的证明。
4. **服务 offer 与包装**（12%）—— 产品化且清晰可读（具名的 sprint/audit）对照模糊不清。考察包装成熟度。
5. **证据与可信度**（12%）—— 具名客户、可量化的成果、case study 的深度。超越单纯声称的证据。
6. **企业就绪度 / 商业成熟度**（10%）—— 表明其能够拿下并持续承接 SaaS/fintech/B2B/enterprise 业务的信号（流程、logo、规模、合同）。
7. **思想领导力 / 内容存在感**（8%）—— 自有的 POV：文章、演讲、newsletter、框架。深度优先于数量。
8. **定价透明度与合作模式**（5%）—— 定价/合作方式是否清晰可读？产品化对照定制化对照不透明。
9. **[客户的战略张力]**（5%，作为标记；**两极都要打分、分别报告**）—— 从客户的 positioning brief 中读取张力名称和轴描述。将两极都绘制出来；两极之间的差距就是洞察所在。客户的目标象限是最重要的发现：还有谁已经身处该象限？

## 评分量表（1–5 分，适用于维度 1–8）

将每一个分数都锚定到可观察的证据。以下为通用描述；在各维度上调整具体内容，但保持等级含义不变。

- **1 —— 缺失 / 泛泛。** 无可辨识的定位或工艺；与模板别无二致。构成实质性的负面资产。
- **2 —— 低于标准。** 有一定意图但不一致、模仿痕迹明显或缺乏说服力。经不起并排比较。
- **3 —— 合格 / 基本功。** 扎实、专业、平淡无奇。达到预期，但任何人都可做到、无法独占。
- **4 —— 强 / 独特。** 明显优于同行；是买家会注意到并加以引用的真正优势。
- **5 —— 定义品类。** 同类最佳、可独占、难以模仿。树立了他人追随的标准。

### 张力轴（维度 9）—— 每项打 1–5 分

从客户的 positioning brief 中读取轴标签及其 1/3/5 分锚点。以 memorability × credibility 张力为例，锚点示例如下：

- **Memorability（记忆度）** —— 1：转瞬即忘 · 3：在特定语境下可识别 · 5：令人难忘、被人谈论、独特且可独占。
- **Credibility（可信度）** —— 1：感觉有风险/业余 · 3：安全、合格、平淡 · 5：受 enterprise 信赖、显而易见的安全选择。

将各竞品绘制到张力 2×2 图上。客户的目标象限已在 positioning brief 中命名。还有谁占据该象限，是本次 benchmark 最重要的发现。

## 如何收集数据

对每个竞品，按以下顺序处理各维度（先获取成本最低的信号）：

1. **竞品自己的网站** —— 定位、语调、offer 包装、定价姿态、具名客户、manifesto/POV。截图首页 + 一个 case study。
2. **case study / 作品** —— 证据深度、可量化的成果、客户名称。区分*声称的*（"我们交付了 X"）与*已证实的*（有指标、有具名、可核实）。
3. **评测目录** —— 印证客户、项目规模、合作模式 → 可信度与企业就绪度（例如 Clutch.co 或所在细分领域的同类平台）。
4. **LinkedIn** —— 团队规模/模式、创始人叙事、内容更新节奏 → 思想领导力、模式。
5. **作品集 / 工艺平台** —— 工艺层级（使用该细分领域原生的展示形式：设计板、showreel、已发布的样本等）。
6. **内容渠道** —— newsletter/演讲/文章 → 思想领导力深度。

**每个维度需记录：** 分数、一行理由，以及支撑该分数的来源链接/截图。没有证据就不打分。

## 偏见控制

- **不要给出单一的复合分数。** 维度分数和张力图要分开报告。加权平均会掩盖那些真正重要的不对称性。
- **声称对照证实。** 对于未经第三方印证的自我宣称，应下调其可信度/证据分数。网站文案是营销，不是事实。
- **审美亲和偏见。** 评审可能对与自己审美相近的 studio 打高分，而对竞争对手的商业实力打低分。工艺与可信度要独立打分；一个"无聊"的网站可能正在赢得更大的客户。
- **新近性 / 醒目度偏见。** 获奖、展示性作品很抢眼，但可能缺乏商业深度——在为可信度打分前，用目录/客户加以核实。
- **幸存者偏差。** 那些曝光度高、营销到位的 studio 并不是市场的全部；留意那些经由目录/评价发现的、实力强但低调的经营者。
- **跨集合校准，而非孤立打分。** 定稿前，把所有分数并排重新审视——"4 分"对每个竞品必须含义相同。调整离群值。

## Competitor profile card（输出格式）

为每一个被评估的竞品产出一张 card——这是报告组装时的原子单位：

```
## <竞品名称>
- **画像 / Tier:** <定位姿态 · 专长领域 · 规模区间> / <Direct | Adjacent | Aspirational>
- **一句话定位:** <他们如何用自身的话语来定位自己>
- **模式 / 规模 / 地域:** <solo|micro|boutique> · <地区> · <定价/合作模式>
- **知名客户 / 证据:** <具名，并标注 proven/asserted>

### 维度分数
| 维度 | 分数（1–5） | 理由（一行） | 来源 |
|---|---|---|---|
| 定位清晰度与独特性 | | | |
| 品牌语调 / 文字独特性 | | | |
| 视觉识别与站点工艺 | | | |
| 服务 offer 与包装 | | | |
| 证据与可信度 | | | |
| 企业就绪度 / 商业成熟度 | | | |
| 思想领导力 / 内容存在感 | | | |
| 定价透明度与合作模式 | | | |

### 张力图
- **[来自 positioning brief 的轴 1]:** <1–5> — <理由>
- **[来自 positioning brief 的轴 2]:** <1–5> — <理由>
- **象限:** <high/high | high-1/low-2 | low-1/high-2 | low/low>

### 对 [client] 的解读
- **值得借鉴的优势:** <…>
- **可利用的弱点 / 由此暴露的 white-space:** <…>
- **对 [client] 的威胁:** <…>
```

将填写完成的 card 以及张力图交给 `competitive-report-structure`。

## 反模式

- **对张力轴取平均。** 客户战略张力的两极必须独立打分、分别报告。取平均会毁掉洞察——两极之间的差距本身就是结论。
- **无证据打分。** 每一个分数都需要一行理由和一个来源链接。没有证据的分数只是主观意见，而非 benchmark。
- **制造单一的复合分数。** 维度分数要逐项报告。加权平均会掩盖那些对定位至关重要的不对称优势。
- **套用通用量表锚点而不加调整。** 1–5 分的锚点必须针对具体维度和竞品集合进行校准。通用描述只是起点，不是固定标准。
- **在竞品集合尚未圈定前就启动。** 先使用 competitive-platform-analysis 产出一个分层、已精简的集合。对未圈定的列表打分，会把精力浪费在不相关的竞品上。
