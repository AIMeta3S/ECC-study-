# 预测市场 Oracle 研究

当考虑将预测市场作为数据源、预测输入、类 oracle 信号或决策智能层时，使用此 skill。

## 护栏

- 不要将市场价格视为客观事实。
- 不要提供投资建议或交易推荐。
- 将 venue 机制、流动性、激励和 resolution 规则与隐含信号区分开来。
- 指出操纵、流动性稀薄、陈旧市场和结果模糊的情况。
- 对于链上或与执行挂钩的系统，在授予任何写权限之前，先运行 `llm-trading-agent-security`。

## 研究工作流

1. 定义该信号旨在支撑的决策。
2. 查找相关的市场、事件、标签和 venues。
3. 记录市场隐含概率，并附带时间戳和来源链接。
4. 评估信号质量：
   - 流动性
   - 价差
   - 市场存续时间
   - 交易者/激励集中度（如可知）
   - resolution 权威方
   - 地域或账户限制
5. 与非市场来源进行比较，如公开文件、新闻、民调、研究报告、客户数据或内部 KPI。
6. 针对所述决策，建议该信号是可用、偏弱还是不适用。

## 集成模式

- 研究助手：为人类分析师提供基于来源的上下文。
- Dashboard 信号：将市场隐含概率与内部指标并列。
- Agent memory 输入：可在后续检索的带时间戳信号。
- 告警输入：当概率、价差或流动性越过 threshold 时发出通知。
- 情景规划：比较多个事件结果，但不自动执行交易。

## 输出契约

使用：

1. 决策上下文
2. 市场来源
3. 信号质量
4. 对比来源
5. 集成建议
6. 注意事项

以如下内容结尾：

```text
预测市场信号是信息性输入，不构成投资建议。
```
