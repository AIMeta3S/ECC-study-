# 投资人材料

构建一致、可信且经得起质疑的面向投资人的材料。

## 何时启用

- 创建或修订 pitch deck
- 撰写 investor memo 或 one-pager
- 构建财务模型、里程碑计划或 use-of-funds 表格
- 回答加速器或孵化器申请问题
- 围绕单一 source of truth 对齐多份融资文档

## 黄金法则

所有投资人材料必须相互一致。

在撰写之前，创建或确认唯一的 source of truth：
- traction 指标
- 定价与收入假设
- 融资规模与融资工具
- use of funds
- 团队简介与头衔
- 里程碑与时间线

如果出现相互矛盾的数字，先停下来解决矛盾，再开始起草。

## 核心工作流

1. 盘点权威事实
2. 识别缺失的假设
3. 选择材料类型
4. 以显式逻辑起草材料
5. 对照 source of truth 交叉核对每一个数字

## 材料指南

### Pitch Deck
推荐流程：
1. 公司 + wedge
2. 问题
3. 解决方案
4. 产品 / demo
5. 市场
6. 商业模式
7. traction
8. 团队
9. 竞争 / 差异化
10. ask
11. use of funds / 里程碑
12. 附录

如果用户想要 web 原生的 deck，将本 skill 与 `frontend-slides` 配合使用。

### One-Pager / Memo
- 用一句简洁的话说明公司做什么
- 说明为什么是现在
- 尽早纳入 traction 和证明点
- 让 ask 精确
- 让主张易于验证

### 财务模型
包含：
- 显式假设
- 必要时给出 bear / base / bull cases
- 清晰的分层收入逻辑
- 与里程碑挂钩的支出
- 在决策取决于假设时进行敏感性分析

### 加速器申请
- 准确回答所问的问题
- 优先突出 traction、洞察与团队优势
- 避免夸大宣传
- 保持内部指标与 deck 和模型一致

## 需避免的红旗

- 无法验证的主张
- 缺少假设的模糊市场规模估算
- 不一致的团队角色或头衔
- 收入计算无法干净加总
- 假设脆弱却表现出过度确定

## Quality Gate

交付之前：
- 每个数字都与当前的 source of truth 一致
- use of funds 和收入分层正确加总
- 假设清晰可见，不被埋没
- 叙事清晰，没有炒作性语言
- 最终材料在合伙人会议上经得起质疑
