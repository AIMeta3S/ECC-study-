# Itô Trade Planner

当用户需要为预测市场想法、basket 调整、venue 对比或手动执行计划构建结构化工作表时，使用此 skill。

此 skill 有意设计为非执行性。它生成检查清单和参数表，供用户手动审阅。

## 护栏

- 不要说某笔交易是好的、坏的、最优的或被推荐的。
- 不要提供投资建议或仓位规模建议。
- 不要下单、撤单、路由或签署订单。
- 不要索取私钥、助记词、交易所密码或钱包凭证。
- 在任何工作流从研究阶段进入具备执行能力的工具之前，必须获得用户的明确批准。

## 规划工作流

1. 将用户的想法复述为中立的假设。
2. 识别市场、venues、underliers、resolution rules、手续费以及数据时效性约束。
3. 如果配置了 `ITO_API_KEY` 并且用户提出请求，则读取 Itô basket 元数据。
4. 构建手动工作表：
   - 市场/underlier
   - venue
   - 数据源
   - 当前可观测价格或状态
   - resolution rule
   - 流动性注意事项
   - 待解决问题
   - 手动操作链接或下一步审阅步骤
5. 在讨论自动化、密钥、venue 授权或资金约束之前，运行 `prediction-market-risk-review`。

## 允许的用语

使用：

- "手动规划工作表"
- "行动前需要回答的问题"
- "可观测的 venue 数据"
- "风险与约束审查"

避免：

- "你应该买入/卖出"
- "最佳交易"
- "保证"
- "无风险"
- "最优规模"

## 输出契约

每个计划以此结尾：

```text
这是一个规划工作表，而非投资或交易建议。请审阅 venue
规则并自行做出任何交易决策。
```
