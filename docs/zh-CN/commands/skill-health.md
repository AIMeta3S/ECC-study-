## Usage

```
/skill-health                    # 完整 dashboard 视图
/skill-health --panel failures   # 仅失败聚类面板
/skill-health --json             # 机器可读 JSON 输出
```

## What to Do

1. 使用 --dashboard flag 运行 skills-health.js 脚本
2. 将输出展示给用户
3. 如果有 skill 正在衰退，高亮显示并建议运行 /evolve
4. 如果有待处理的修正提案，建议审查它们

## Panels

- **Success Rate (30d)** — 显示每个 skill 每日成功率的 sparkline 图表
- **Failure Patterns** — 聚类的失败原因，配水平条形图
- **Pending Amendments** — 待审查的修正提案
- **Version History** — 每个 skill 的版本快照时间线
