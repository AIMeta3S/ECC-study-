# AI-First Engineering

当为使用 AI 辅助代码生成进行交付的团队设计流程、评审和架构时，使用此 skill。

## 流程转变

1. 计划质量比打字速度更重要。
2. eval 覆盖率比基于个案的信心更重要。
3. 评审重点从语法转向系统行为。

## 架构要求

优先选择对 agent 友好的架构：
- 显式边界
- 稳定的契约
- 类型化接口
- 确定性测试

避免隐式行为散布在隐藏的约定中。

## AI-First 团队中的代码审查

审查以下方面：
- 行为回归
- 安全假设
- 数据完整性
- 失败处理
- 发布安全

尽量减少在自动化已覆盖的风格问题上花费的时间。

## 招聘与评估信号

优秀的 AI-first 工程师：
- 清晰地分解模糊的工作
- 定义可衡量的验收标准
- 产出高信号的 prompt 和 eval
- 在交付压力下执行风险控制

## 测试标准

提高生成代码的测试门槛：
- 涉及领域必需的回归覆盖率
- 显式的边界情况断言
- 接口边界的集成检查
