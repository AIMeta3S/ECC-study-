# Homelab 网络搭建

使用本 skill 设计一个家庭或小型实验室网络，使其能够在无需全面重构的前提下扩展。

## 何时使用

- 规划新的家庭网络，或重新设计仅有 ISP 路由器的部署。
- 选择网关、交换机和接入点的角色。
- 设计 IP 段、DHCP 作用域、静态预留和 DNS。
- 为将来的 VLAN、Pi-hole、NAS、实验室服务器或 VPN 访问做准备。
- 排查出现双重 NAT、不稳定 Wi-Fi 或服务器地址不断变化的新网络。

## 工作原理

首先分离设备角色：

```text
Internet
  |
Modem 或 ONT
  |
网关或路由器            NAT、防火墙、DHCP、DNS、inter-VLAN routing
  |
管理型交换机            有线客户端、AP 上联、可选的 VLAN trunk
  |
接入点                  仅 Wi-Fi；理想情况为有线回程
服务器与 NAS            稳定地址、DNS 名称、监控
客户端与 IoT            DHCP 池，若支持 VLAN 则后续再做隔离
```

选择与运营商匹配的网关，而不仅看功能清单：

| 选项 | 最适合 | 说明 |
| --- | --- | --- |
| ISP 路由器 | 仅基础互联网 | 控制力有限，且 VLAN 支持通常较差 |
| UniFi 网关 | 托管型家庭网络 | UI 良好，但存在生态锁定 |
| OPNsense 或 pfSense | 灵活的 homelab | 强大的 VLAN、防火墙、VPN 和 DNS 控制 |
| MikroTik | 高级网络用户 | 功能强大，但容易误配置 |
| Linux 路由器 | 折腾爱好者 | 在作为主网关使用前，先记录好回滚方案 |

## IP 规划

当你预期会使用 VPN 时，应避免使用最常见的默认网段 `192.168.1.0/24`。
它经常与酒店、办公室和 ISP 路由器发生冲突。

```text
小型 homelab 示例规划：

192.168.10.0/24  受信任客户端
192.168.20.0/24  IoT 与媒体设备
192.168.30.0/24  服务器和 NAS
192.168.40.0/24  访客 Wi-Fi
192.168.99.0/24  网络管理

网关约定：.1
基础设施预留：.2 到 .49
动态 DHCP 池：.50 到 .240
备用空间：.241 到 .254
```

本地名称使用 `home.arpa`。它是为家庭网络保留的，可避免像 `home.lan` 这类临时名称带来的泄露/冲突问题。

```text
nas.home.arpa
pihole.home.arpa
gateway.home.arpa
switch-01.home.arpa
```

## DHCP 与 DNS

- 对任何你需要 SSH 登录、收藏、监控或作为服务对外暴露的设备，使用 DHCP 预留。
- 在有意识地部署本地解析器之前，将网关作为 DNS 下发。
- 如果使用 Pi-hole 或其他 DNS 过滤器，先为它分配预留，再将 DHCP 的 DNS 选项指向该地址。
- 在每个子网中保留一个小的静态/预留范围，以免更换设备时与动态租约冲突。

## 布线与 Wi-Fi

- 能够走 Ethernet 线时，优先使用有线 AP 回程而非 mesh。
- 预算允许的话，为 AP 和摄像头使用 PoE 交换机。
- 给每根网线的两端都贴上标签，并维护一份简单的端口对应表。
- 如果经常停电，将网关、交换机、DNS 服务器和 NAS 接入 UPS 供电。

## 示例

### 新手升级

目标：保留 ISP 路由器，但稳定一个小型实验室。

1. 为 NAS、Pi 以及任何 SSH 主机设置 DHCP 预留。
2. 将本地名称迁移到 `home.arpa`。
3. 关闭次要路由器或 AP 上重复的 DHCP 服务器。
4. 将主 AP 改为有线连接，而不是依赖无线回程。

### 面向 VLAN 的规划

目标：为将来的分段做好准备，但不立即启用。

1. 为受信任网络、IoT、服务器、访客和管理分别选择不重叠的 /24 网段。
2. 在每个子网中将 .1 预留给网关，.2-.49 预留给基础设施。
3. 购买支持 VLAN 和 inter-VLAN 防火墙规则的网关和交换机。
4. 记录哪些 SSID 和交换机端口最终会对应到每个网络。

## 反模式

- 没有理由或文档说明的双重 NAT。
- 在已规划 VPN 访问的情况下仍使用 `192.168.1.0/24`。
- 为 NAS、Pi-hole、Home Assistant 或其他服务主机使用动态地址。
- 把消费级路由器改作 AP 使用，却仍开启其 DHCP 服务器。
- 扁平网络中摄像头、智能插头、笔记本和服务器都共享同一个信任边界。
