# custom-install/zh-cn 资源依赖检查报告

## 审计范围

逐个读取 `custom-install/zh-cn/` 下 command、agent、skill、rules 四类目录中的每个文件，检查其引用/调用/触发的所有外部资源（command、skill、agent、rules、config、script 及其它文件）在 zh-cn 对应位置是否存在；并关注"A 引用的文件由 B 生成"的情况。

- **commands**：32 个
- **agents**：19 个
- **skills**：21 个 SKILL.md + continuous-learning-v2 内 12 个文件
- **rules**：33 个（common 10 / python 6 / typescript 5 / vue 5 / web 7）
- 合计约 105 个文件

## 核心结论

共发现 **15 处引用在 zh-cn 下找不到对应资源**：

- **15 处"漏拷贝"**——根目录存在、zh-cn 未拷贝（7 command、5 skill、2 script、1 plugin 配置）
