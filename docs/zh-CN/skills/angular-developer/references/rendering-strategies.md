# 渲染策略

Angular 支持多种渲染策略，以针对 SEO、性能和交互性进行优化。

## 1. 客户端渲染（CSR）

**默认策略。** 内容完全在浏览器中渲染。

- **适用场景**：交互式 dashboard、内部工具。
- **优点**：配置最简单，服务器成本低。
- **缺点**：SEO 较差，初始内容可见速度较慢（必须等待 JS）。

## 2. 静态站点生成（SSG / Prerendering）

内容在 **构建时** 预渲染为静态 HTML 文件。

- **适用场景**：营销页面、博客、文档。
- **优点**：初始加载最快，SEO 优秀，对 CDN 友好。
- **缺点**：内容更新需要重新构建，不适用于用户特定数据。

## 3. 服务端渲染（SSR）

内容在服务器端为 **初始请求** 渲染。后续导航在客户端进行（SPA 风格）。

- **适用场景**：电商产品页面、新闻站点、个性化动态内容。
- **优点**：SEO 优秀，初始内容可见速度快。
- **缺点**：需要服务器（Node.js），服务器成本/延迟较高。

## Hydration

Hydration 是让服务端渲染的 HTML 在浏览器中具备交互能力的过程。

- **Full Hydration**：整个应用一次性变为可交互。
- **Incremental Hydration**：（进阶）按需使用 `@defer` 区块让部分内容变为可交互。
- **Event Replay**：捕获并回放在 hydration 完成前发生的用户事件。

## 决策矩阵

| 需求                   | 策略                |
| :--------------------- | :------------------ |
| **SEO + 静态内容**     | SSG                 |
| **SEO + 动态内容**     | SSR                 |
| **无 SEO + 高交互性**  | CSR                 |
| **混合**               | Hybrid（基于路由）  |
