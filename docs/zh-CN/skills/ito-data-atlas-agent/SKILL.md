# Itô Data Atlas Agent

使用本 skill 设计一个 agent，用于监控数据源、构建候选预测市场篮子、起草参数变更，并将结果交给人工审核。

本 skill 描述架构与工作流，不执行实盘交易。

## 护栏

- 所有执行操作须经过明确的人工批准。
- 仅对只读 Itô 数据访问要求 `ITO_API_KEY`，除非独立的私有实现明确添加了执行控制。
- 不得持久化用户私有数据，除非目标仓库已具备存储约定且用户明确要求。
- 不得在公开文档中暴露私有策略逻辑、场所凭据或本地路径。

## 架构模式

采用四条通道：

1. 研究收集器：公共网络、X、GitHub、场所文档、API 元数据，以及在存在门控访问时的 Itô 只读端点。
2. 篮子起草器：将来源转化为候选标的、权重、规则与问题。
3. 风险审查员：检查数据新鲜度、场所限额、结算歧义、合规说明以及 prompt-injection 暴露面。
4. 人工编辑器：开启一个对话或 UI 状态，用户可在其中批准、拒绝、调整或要求补充更多研究。

## 工作流

1. 定义用户目标与排除的操作。
2. 列出数据源与访问要求。
3. 起草篮子规格，为每个标的提供溯源信息。
4. 产出可编辑的参数，而非可执行的订单。
5. 存储审计追踪：输入、模型输出、来源与人工决策。

## 实用 skill 链

- `deep-research` 用于来源收集。
- `x-api` 用于获取当前社交/事件信号。
- `ito-market-intelligence` 用于场所与标的背景信息。
- `ito-basket-compare` 用于用户知识库匹配。
- `prediction-market-risk-review`，在任何具备执行能力的集成之前使用。

## 输出契约

返回一个可直接落地的工作流规格，包含：

- 数据源
- 访问门控
- agent 角色
- 人工批准节点
- 存储/审计边界
- 非目标
