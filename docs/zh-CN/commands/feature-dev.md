---
description: 引导式功能开发，注重对代码库的理解与架构设计
---

一种结构化的功能开发工作流，强调在编写新代码之前先理解已有代码。

## 阶段

### 1. 发现

- 仔细阅读功能需求
- 明确需求、约束和验收标准
- 如果需求模糊，提出澄清性问题

### 2. 代码库探索

- 使用 `code-explorer` 分析相关的已有代码
- 追踪执行路径和架构层
- 理解集成点和约定

### 3. 澄清问题

- 呈现探索阶段的发现
- 提出有针对性的设计和边缘情况问题
- 在继续之前等待用户回复

### 4. 架构设计

- 使用 `code-architect` 设计该功能
- 提供实现蓝图
- 在开始实现之前等待批准

### 5. 实现

- 按照已批准的设计实现该功能
- 在合适的情况下优先采用 TDD
- 保持提交小而聚焦

### 6. 质量审查

- 使用 `code-reviewer` 审查实现
- 处理关键和重要的问题
- 验证测试覆盖率

### 7. 总结

- 总结所构建的内容
- 列出后续事项或限制
- 提供测试说明
