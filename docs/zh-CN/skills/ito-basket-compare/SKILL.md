# Itô 篮子对比

使用此 skill 将一个篮子、主题或市场集合与用户的知识库、投资组合笔记、研究备忘录、CRM 上下文或明确陈述的论点进行对比。

此 skill 是只读的。它不会推荐交易。它帮助用户在决定如何行动之前，检查适配度、风险敞口、假设和缺失的上下文。

## 护栏

- 不要提供投资建议，也不要告诉用户买入、卖出、持有、对冲、加杠杆或确定交易规模。
- 不要执行、准备或提交订单。
- 不要使用私密文档，除非用户明确指向它们。
- 仅在用户明确请求后，使用 `ITO_API_KEY` 获取只读的 Itô 篮子/市场数据。
- 如果与财务数据对比，保护隐私，仅汇总对比所需的字段。

## 对比模式

### 篮子 vs 知识库

1. 识别篮子主题和底层标的。
2. 检索用户相关的笔记、文档或记忆片段。
3. 将每个底层标的映射到主张、来源、不确定性和过时的假设。
4. 返回对齐的信号、冲突的信号和缺失的研究。

### 篮子 vs 投资组合笔记

1. 解析用户的观察列表、持仓汇总或敞口笔记。
2. 对比主题、地域、时间跨度和事件结果。
3. 标记集中度、相关性和重复的叙事敞口。
4. 避免推荐；将输出表述为检查和提问。

### 篮子 vs 财务上下文

1. 仅接受用户提供的或明确选择的财务上下文。
2. 识别流动性、回撤、时间跨度和约束条件的不匹配。
3. 询问缺失的约束条件，而不是猜测。

## 输出契约

使用以下结构：

1. 篮子摘要
2. 对比目标
3. 匹配项
4. 冲突或过时的假设
5. 缺失的上下文
6. 用户行动清单

以此结尾：

```text
此对比仅供参考，不构成投资或交易建议。
```
